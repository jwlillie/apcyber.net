Your assignment

You administer the network for Ridgeline Outfitters. New hires need domain accounts so they can reach shared resources. Provision the four accounts below on RIDGE-DC1, each in its department's organizational unit.

  • Dana Whitfield — Operations manager — Operations\OpsManagers
  • Renata Cole — Fulfillment manager — Fulfillment\FulfillmentManagers
  • Theo Park — Permanent fulfillment associate — Fulfillment\FulfillmentStaff
  • Avery Lin — Seasonal fulfillment associate — Fulfillment\SeasonalStaff

Account standard for every new hire:

  • Display name: First Last
  • Logon name: first initial + last name, domain @ridgeline.local (e.g. dwhitfield)
  • Initial password: Tr@ilhead2026, and the user must change it at first logon

For the seasonal associate only:

  • Permit sign-in just on weekday business hours, 7:00 a.m.–6:00 p.m., Monday–Friday
  • Set the account to expire at the end of the current calendar year
