Restrict a folder with NTFS permissions & disable inheritance

Lock down a sensitive directory on a file server so only the right group can reach it, then stop permissions from flowing down from the parent. Work in the simulated security console on the left; the checklist tracks you automatically.

Scenario

You administer the file server VAULT-FS01 at Meridian Freight Co. The internal audit team keeps quarterly working papers in E:\AuditWorkpapers. Right now the folder simply inherits everything from the drive root, so far more people can open it than should.

Your job: give the security group MERIDIAN\Audit-Leads exclusive control of the folder, and cut off the inherited access so general Users can no longer reach it.
