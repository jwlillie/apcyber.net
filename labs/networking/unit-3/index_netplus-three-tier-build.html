Build a Redundant Three-Tier Campus Network

Brightleaf Community College is re-cabling its campus core. Cable the access, distribution, and core tiers so a single switch or link failure never isolates a building.

N10-009: 1.6 (verify) APNET: 3.2.C APNET: 3.1.B

Choose two device ports, then activate Run cable to create a link. Each port accepts one cable.

    Design brief

    • Give every access switch an uplink to both distribution switches.
    • Give every distribution switch an uplink to both core switches.
    • Run one backbone cable between the two core switches.
    • No extra cables — a clean design has exactly the links above.

      Design questions

      Q1 — Surviving a failure

      A custodian accidentally powers off one distribution switch. Because each access switch was cabled to both distribution switches, what happens to user traffic?

      Q2 — Layer roles

      Which tier's main job is fast transport between distribution blocks rather than enforcing per-user access policy?

      Q3 — Topology trade-off

      Why cable each access switch to two distribution switches instead of one?
