Setup Guide

Get Your Free AI Key

Three AI tools on this site require your own API key — the Socratic Tutor, Flashcard Generator, and Cross-Unit Synthesis Quiz. Your key is stored only in your browser and never sent to our server. Follow the steps below to get set up in under 5 minutes.

✓ Recommended for Students
Google Gemini

Gemini is Google's AI — and the easiest option here. The free tier gives you 15 requests per minute with no credit card required. This is the best starting point for most students.

✓ Free tier available
15 requests / minute
No credit card needed
Key format: AIza...
1
Go to Google AI Studio
Open aistudio.google.com in your browser. This is Google's free platform for accessing Gemini. Sign in with any Google account — a school Gmail works fine.
Open AI Studio ↗
2
Click "Get API key"
In the left sidebar, look for the Get API key button (it has a key icon). Click it. You'll be taken to the API key management page.
💡
If you see a welcome screen first, just click through it. The key option is always in the left sidebar.
3
Create API key
Click the blue Create API key button. A dialog will ask you to select a Google Cloud project. If you don't have one, click Create API key in new project — Google creates one for you automatically, no setup needed.
4
Copy your key
Your new key will appear — it looks like this:
AIzaSyAbc123XYZ...
Click the copy icon next to it. Keep this key private — don't post it in a document or share it publicly.
5
Paste it into the tool
Return to the AP Cybersecurity tool you want to use. Find the AI Provider & Key section at the top of the setup screen, make sure Google Gemini is selected, paste your key, and click Save Key.
Where to enter your key on each tool
1
Open the tool (Socratic Tutor, Flashcard Generator, or Synthesis Quiz)
2
At the top of the setup screen, find the AI Provider & Key Required section
3
Select Google Gemini (Free) from the dropdown
4
Paste your key into the password field and click Save Key
5
The key is saved for your browser session — you'll need to re-enter it if you close the tab
★
Free tier limits: 15 requests per minute, 1 million tokens per minute, and 1,500 requests per day. For AP class use, this is more than enough. If you hit the limit, wait 60 seconds and try again.
OpenAI (ChatGPT)

OpenAI makes ChatGPT. Their API uses GPT-4o Mini for this site — a fast, capable model. OpenAI requires a small credit purchase to use the API, but costs are very low: roughly $0.002 per quiz session.

Requires $5 minimum credit
~$0.002 per session
Key format: sk-...
⚠
Note for students: OpenAI requires a credit card to purchase API credits. If you don't have one, use the free Gemini option instead — it works just as well for this site.
1
Create an OpenAI account
Go to platform.openai.com and sign up. This is separate from ChatGPT — it's the API platform for developers. Use any email address to register.
Open OpenAI Platform ↗
2
Add billing credits
Click Settings in the top-right → Billing → Add payment method. Add a credit card and purchase $5 in credits. This is the minimum amount and will last for hundreds of quiz sessions.
3
Create an API key
Click API Keys in the left sidebar → Create new secret key. Give it a name like "AP Cyber" and click Create. Your key looks like:
sk-proj-abc123...
Copy it immediately — OpenAI only shows it once.
⚠
Copy it now. Once you close the dialog, the key is hidden forever. If you lose it, you'll need to create a new one.
4
Paste it into the tool
On the AP Cybersecurity tool, select OpenAI GPT-4o Mini from the provider dropdown, paste your key, and click Save Key.

Like OpenAI, Anthropic only shows the key once.
4
Paste it into the tool
On the AP Cybersecurity tool, select Anthropic Claude Haiku from the provider dropdown, paste your key, and click Save Key.

Frequently Asked Questions
Is my API key safe? Can anyone see it? ▼
Your key is stored in your browser's sessionStorage — it exists only in your browser tab and is never transmitted to apcyber.net's server. When you use an AI tool, your browser sends the request directly to the AI provider (Google, OpenAI, or Anthropic) using your key. The key disappears when you close the tab. That said, treat it like a password: don't paste it into a public document, Discord, or email.
Why do I have to enter my own key? Why doesn't the site just have one? ▼
This is an intentional decision to keep the site free and sustainable. A shared key would cost money with every student request, could be abused, and would require billing and rate limiting infrastructure. Using your own key means your usage is charged to your account only, the site has no operating costs, and your activity is private.
Do I need to re-enter my key every time? ▼
Yes, once per browser session. sessionStorage clears when you close the tab or browser. If you're using this regularly, you may want to keep your key saved securely in a password manager so you can paste it quickly. We chose sessionStorage over longer-term storage specifically so the key doesn't persist on shared or school computers.
I'm a teacher — can I get one key for the whole class? ▼
Technically yes — you could share one Gemini key with students since it's free. However, be aware that a shared key could hit rate limits if many students use it simultaneously. The free Gemini tier allows 15 requests per minute total across all users of the same key. For larger classes, having each student get their own free key is the better approach.
Which AI tools on this site need a key? ▼
Three tools require an API key: the Socratic AI Tutor, the Flashcard Deck Generator, and the Cross-Unit Synthesis Quiz. All other tools — the Quiz Engine, AP Exam Simulator, Attack Chain Mapper, Spot the Attack, Defense-in-Depth Builder, and Vocab Matcher — are fully static and require no key at all.
I entered my key and I'm getting an error. What do I do? ▼
Check these common issues: (1) Make sure you selected the right provider — a Gemini key won't work if OpenAI is selected. (2) Copy the key again from the provider's website to ensure no extra spaces. (3) For Gemini, make sure the API is enabled in your Google Cloud project — AI Studio usually handles this automatically but sometimes requires confirmation. (4) For OpenAI/Anthropic, make sure you have a positive credit balance.
