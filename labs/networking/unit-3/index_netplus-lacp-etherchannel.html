Bonding the Backbone

N10-009 · 2.2 AP NET · 3.2.C AP NET · 3.3.C Skills 1.C / 1.D

Scenario

Cedar Hollow Public Library is moving its digital-archive collection onto a new media server. A single 1 Gbps uplink between the distribution switch CHPL-DSW1 and that server keeps saturating during the morning catalog sync. You'll bond two switch ports into one logical link so the server gets more throughput and keeps working if one cable fails. Use the Link Aggregation Control Protocol (LACP) so both sides negotiate the bundle automatically, then place the bundle on the archive VLAN and verify it came up.
