Your Objective

Get MLO-IDF2-SW3 onto the patched firmware, then answer the review questions.

You're the network technician for Marsh & Linden Outfitters. The access-layer switch MLO-IDF2-SW3 in the second-floor IDF is running NB-OS 4.10.3, which has a published advisory. Northbridge released the patched image NB-OS 4.12.7 (NB-OS-4.12.7-secure.nbf). Bring the switch up to date without taking the running image offline mid-import.

Task Checklist

  • Import NB-OS-4.12.7-secure.nbf into the inactive image bank.
  • Set the bank holding 4.12.7 as the boot image.
  • Restart the switch and confirm it is running 4.12.7.
