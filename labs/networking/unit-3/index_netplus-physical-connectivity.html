Brightwater Clinic: Physical-Layer Fault Isolation

You cover the help desk for Brightwater Veterinary Clinic. After a weekend rewiring job, two machines lost their network connection. Use the link LEDs, the diagnostic console, and a structured set of cable swaps to find which physical segment is at fault on each machine — without shotgunning parts. The clinic LAN is 10.20.5.0/24; the switch is SW-CORE-1.
