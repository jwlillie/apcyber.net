Why this matters

A domain controller's System State bundles the Active Directory database (NTDS.dit), SYSVOL, the registry, and boot files. Lose it without a backup and you can't perform an authoritative restore of AD.

A daily schedule keeps recovery points fresh; a one-time immediate backup gives you a known-good restore point right now, before any risky change.
