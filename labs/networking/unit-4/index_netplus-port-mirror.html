The security team just racked a new IDS sensor in the Brightwater Transit data center. Its capture interface is patched into the core switch BWT-DSW-01, but it can only inspect traffic if you mirror the WAN uplink to it. Your shift task: stage the analyzer port, build a monitor session that copies received traffic from the uplink to the sensor, and save the configuration so it survives a reboot.
