Hand-Configuring a Tablet When DHCP Is Down

You just started as the IT helper at Driftwood Coffee Roasters. The new countertop tablet at the register — staff call it the AuroraTab — came up with no network access. The back-office DHCP server is offline for maintenance, so the tablet can't lease an address automatically. Set its IP configuration by hand so the point-of-sale app can reach the register server, then join it to the staff Wi-Fi.
