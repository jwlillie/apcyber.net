Lab scenario

Tier the switch's event logging by severity

You just started as the security admin at Foxglen Outfitters, a regional outdoor-gear distributor. The managed access switch in the warehouse mezzanine closet ships with logging switched off. Before it goes into service you need to turn logging on, point it at the company's log aggregator, and tier which event severities are kept in fast volatile memory versus written to the device's limited persistent flash — then make the change survive a reboot.
