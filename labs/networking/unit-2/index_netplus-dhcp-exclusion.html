Lights-Out Network: Add a DHCP Exclusion Range

N10-009 · 1.6 APNET · 3.3.A APNET · 3.4.B

You are the night-shift admin for Cinder Ridge Observatory. A new scope on obs-dhcp01 hands out addresses on 172.20.16.0/24 across the full range 172.20.16.1 – 172.20.16.254. Trouble is, the telescope mount controllers, weather station, the NAS, and the internal DNS resolver were all given static addresses down at the bottom of that block — and DHCP doesn't know that. Tonight a leased laptop grabbed 172.20.16.7 and knocked the primary mount controller offline.

Stop the bleeding: add an exclusion range so DHCP never leases the static infrastructure block, then verify the leasable pool starts above it.

DHCP Manager obs-dhcp01
Select the scope [172.20.16.0] Cinder Ridge in the tree to begin.
Network 172.20.16.0
Mask 255.255.255.0 (/24)
Gateway 172.20.16.1
DNS option 172.20.16.10
Lease 8 hours
Distribution pool .1 – .254
Range Disposition
Leasable pool currently begins at 172.20.16.1. The static block is unprotected. Add an exclusion, then verify.
