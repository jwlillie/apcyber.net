Team the Server NICs — Survive a Link Failure

N10-009 · 3.1 (provisional) N10-009 · 2.2 (provisional) AP Networking · 3.1.A Host NIC teaming · failover

The archive file server fs‑archive‑01 has two network adapters but relies on only one — if that cable, port, or NIC dies, the server drops off the network mid-backup. Combine NIC1 and NIC2 into one team so the host keeps a single address and stays reachable when a link fails. Then prove it: pull a cable and watch the team carry on. This is teaming on the host itself — no switch port-channel required.
