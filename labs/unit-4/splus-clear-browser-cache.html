Open the ⋮ menu (top-right of the browser) → More tools → Clear browsing data, then set the right time range and tick the required items.

Scenario

You're Priya Nandakumar, a sophomore at Riverton State University. The shared desktop in your residence-hall study lounge runs the Aurora browser, and you've heard about info-stealer malware that scrapes saved browsing artifacts off lab machines.

Before you log off for the night, you want to wipe every locally stored trace of your session — for all time, not just today — so nothing useful is left behind for the next person or for a stealer to harvest.

Task checklist

  • ✓ Open the Clear browsing data dialogMenu → More tools
  • ✓ Set time range to All time
  • ✓ Select Browsing history
  • ✓ Select Download history
  • ✓ Select Cookies and other site data
  • ✓ Select Cached images and files
  • ✓ Select Hosted app data
  • ✓ Click Clear data to complete the wipe

Knowledge check

1. Which time range guarantees that artifacts older than today are also removed?

2. Clearing which item is most directly aimed at stopping session-hijacking via stolen authentication state?

3. Clearing "Download history" removes which of the following?
