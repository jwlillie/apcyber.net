Scenario. You are the junior network tech for the Birchwood Community Library. The branch IDF (rack 3) is getting a new access switch, ACC-SW-2, so the study rooms and the checkout desk can reach the branch media server, MEDIA-SRV-01 at 10.40.12.20. Cat 6a is already pulled to the patch panel; the rack runs on a UPS.

Work order. Rack the switch in the open bay under EDGE-RTR-1, cord it to the UPS battery-backed bank, patch the documented drops to their assigned ports, uplink the switch to the router, connect the server, then verify from the checkout PC. Drop sheet: CHECKOUT → port 3 · STUDY-A → port 11 · router uplink → port 23 · server eth0 → port 15.
