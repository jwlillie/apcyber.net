Provision the Maker Loft Broadband Link

Tidewater Maker Loft just had broadband installed. The ISP left a coax service line terminated at a wall demarcation jack and a pre-activated gateway in the box. You're the on-call field tech — cable it correctly, power it, attach the front-desk PC, and confirm the loft is online.

N10-009 · 1.5 AP NET · 2.3.B assignmentId: netplus-broadband-hookup

Pick a cable, then click a source port and a destination port to run it.

Workspace ready. Start with the WAN side.

Tasks

  1. ✓ Run the ISP demarc jack to the gateway WAN port using the correct service media.
  2. ✓ Connect the gateway LAN port to LOFT-FRONT01's NIC with twisted-pair Ethernet.
  3. ✓ Power the gateway from the wall outlet using the AC-to-DC adapter.
  4. ✓ Click Check connection and confirm LOFT-FRONT01 reports an internet link.
