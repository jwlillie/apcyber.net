You're Marisol Okafor, a junior network tech at Harborline Logistics. The new Pier 7 distribution annex needs its edge router brought online. In the comms-closet rack, the edge firewall (HBL-FW-EDGE) and the optical distribution frame (ODF-7) are already mounted and the fiber risers to the floor switches are terminated on ODF-7. Your job: mount and cable the router HBL-RTR-EDGE-07 so its four LAN downlinks reach ODF-7 and its WAN uplink reaches the firewall — powered so it survives a mains blip. WAN block 203.0.113.0/29; LAN core 10.7.0.0/16.

Rack — Pier 7 comms closet (8U)

copper SFP (RJ-45) LC fiber SFP Tx jack Rx jack linked

Cable color key (this site's convention): ferrule A = aqua = Tx, ferrule B = slate = Rx. A fiber link is correct only when each device's Tx reaches the other end's Rx.

Install & cabling console

1 · Mount the router

Seat HBL-RTR-EDGE-07 in the empty rack unit.

2 · Install SFP transceivers

Match the optic to the media: copper RJ-45 SFP for the copper WAN uplink, LC fiber SFPs for the fiber LAN downlinks.

3 · Power the router

Use the C14 power cable. Pick the outlet that keeps the router up during a mains outage.

4 · Patch LAN downlinks to ODF-7

Each LAN port maps to its matching ODF-7 pair (G1→pair 1 … G4→pair 4). Set the polarity so router Tx lands on the panel Rx jack.

5 · Uplink to the firewall

Patch the router WAN port to the firewall NET-OUT port with the right copper cable.
