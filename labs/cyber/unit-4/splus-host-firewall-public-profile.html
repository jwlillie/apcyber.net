Locking Down the Host Firewall Before a Trip

Scenario. You are Dana Okafor, a field engineer at Brightwave Instruments. IT just handed you a reimaged Windows workstation, but a notification warns that the host firewall is off for the Public network profile. Next week you fly to the Meridian Test & Measurement Expo and will work from hotel and convention-center Wi-Fi — open, untrusted networks. Those connections will be classified under the Public profile, so the firewall must be active there, and a few Brightwave tools need to be permitted through it.

Your tasks:

  1. Turn the host firewall on for the Public network profile.
  2. Without changing the other profiles, allow these through the firewall for the Public profile only:
    • the background service Brightwave Sync Agent
    • the application FieldQuote
    • the application SignalScope
  3. Answer the three review questions in the panel.
