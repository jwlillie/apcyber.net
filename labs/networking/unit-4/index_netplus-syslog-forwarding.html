brief Centralize the Logs

You run the network for Brightwater Outfitters, a small outdoor-gear shop. The edge appliance bw-edge-01 keeps logs only on the box, and its local file rolls over so fast that yesterday's events were already gone by morning. If the appliance reboots — or someone tampers with it — the evidence vanishes with it.

Set sane local retention, then forward the events that matter to the shop's central log collector, logvault.brightwater.lan at 10.20.5.40, so the logs survive off-box. Forward only the System and Firewall facilities — not the chatty everyday noise.
